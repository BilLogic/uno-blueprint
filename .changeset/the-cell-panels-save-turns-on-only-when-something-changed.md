The cell panel's Save turns on only when something changed. Editing a cell, Save stays off until a field differs from what the form opened with — any cell field, or the selected touchpoint's Summary or Role — and turns off again when every edit is taken back. A short line beside Cancel says how many changes are unsaved, or "No changes". A summary seeded with the prose the panel displayed counts as a change only once it is edited. Creating a cell keeps its rule: Create cell turns on once Content has text.

Upgrading a deployment: no action; it comes with the pin.
