The empty-state picture draws its cells as lane-coloured outlines, matching the cover figures. A present cell is now an outline in its lane's ring colour, the step the board draws a cell's ring in, with no fill, and each row's square takes the same colour. A gap is a dashed outline in that same lane colour, so it reads as a cell missing from that lane. Skeleton bars are translucent ink, as the figures' bars are, because a lane-coloured bar with no fill behind it sat on the page at under 2:1. The colours still come from theme tokens, so the picture follows light and dark and a deployment's own lane palette.
